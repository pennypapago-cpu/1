# 第四週：數據週報流程

每週一次，約 5 分鐘。建議固定在週一早上，和新聞雷達的長片選題一起看。

## 頻道主要做的事

1. 打開 YouTube Studio → 左側「數據分析」→ 右上角「進階模式」。
2. 日期範圍選「過去 28 天」（第一次請另外再匯出一份「過去 365 天」，用來確認營利門檻的觀看時數）。
3. 表格上方的分組選「內容」，並確認勾選這些欄位：觀看次數、觀看時間（小時）、訂閱人數、曝光次數、曝光點閱率、平均觀看時長、長度。
4. 右上角下載圖示 →「逗號分隔值 (.csv)」。
5. 解壓縮，找到「表格資料.csv」，上傳給雲端的 Claude，並告訴它 Studio 首頁目前的訂閱總數。

然後說：「分析這週數據」。

## 產出

`reports/YYYY-MM-DD-數據.md`，包含：

- 目標進度：離挑戰目標、保底目標還差多少，每天需要幾人，目前實際速度。
- Shorts 和長片的比較：每千次觀看帶來幾位訂閱、點閱率、觀看時數。
- 每千次觀看帶來訂閱的排行。
- 分析與建議：什麼有效、什麼無效，以及給新聞雷達、腳本編劇、包裝師、Shorts 改編員的具體調整。

## 注意

- 匯出的欄位名稱如果和程式預期的不同，程式會列出實際欄位，再調整即可。中文介面的欄位名稱是依經驗推測，第一次匯出時會確認。
- Shorts 和長片是用影片長度（3 分鐘以下）或標題含 #shorts 來判斷，是近似值。
- CSV 含有頻道數據，會放進 repo 的 `reports/data/`，只有能存取這個 repo 的人看得到。
